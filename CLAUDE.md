# Working on MCP Lightcast

Python 3.12+; package imports use `mcp_lightcast`, not `src.mcp_lightcast`. Run commands with uv.

```bash
uv sync --all-groups --frozen
uv run ruff check src tests
uv run ruff format --check src tests
uv run mypy src
uv run pytest
uv run --group docs python scripts/docs.py build --strict
```

Tests are offline by default. Real API calls require `uv run pytest --live -m live` or `uv run python -m mcp_lightcast.diagnostics --operations`. The latter consumes limited endpoint quotas; do not run it as ordinary CI.

Implement only endpoints verified in the current official Lightcast docs. Keep scopes separate, honor API input types and version families, and preserve warnings. Never replace failures with fabricated data. See `docs/architecture.md`, `docs/review.md`, and `docs/migration.md` for the audited contracts.

The tool reference is generated by `scripts/docs.py`; edit tool signatures and docstrings rather than generated Markdown. GitHub Pages deploys from the documentation workflow on main. Do not put credentials or real posting bodies in test fixtures or documentation.
