# MCP Lightcast 0.4.1

Version 0.4.1 improves shared request ownership and composed workflows while
preserving all 37 MCP tool contracts. Python 3.14 or newer is required.

## Shared request ownership

- `RequestRuntime` owns configuration, token caching, rate spacing, HTTP client construction, and timing. Existing callers retain the shared, lazily configured default.
- Python applications can pass `runtime=` to `create_server` or use `runtime.context()` for direct calls. Reuse an owner when sharing an account's rate budget.
- Metadata caches are isolated by runtime and requested scope as well as endpoint and credential identity.
- The legacy authentication helper honors the selected runtime's request credential provider.
- Request tests cover expired tokens, late 401 replies, cancellation cleanup, and successive event loops without modifying private global caches.

## Composed workflows

The three composed operations are directly callable from `mcp_lightcast.workflows`.
They own client lifetimes, skill deduplication, evidence, and provenance; MCP tools
delegate to the same implementation. Existing Python workflow imports remain
available.

Occupation inference retains partial results after optional downstream failures.
Posting analysis and classifier extraction still require every requested stage
to succeed. Score, confidence, source attribution, and warning locations retain
their existing meanings.

## Compatibility and validation

No migration is required for existing environment or header credential modes.
All 37 tool names, descriptions, annotations, input schemas, and output schemas
remain unchanged. Separate explicit runtimes have independent rate budgets;
multiple processes still require deployment-level coordination.

The underlying refactor passed 156 offline tests and 13 local nginx/TLS proxy
tests, including current and legacy MCP protocols. Lint, formatting, type checks,
strict documentation builds, and built-package checks also passed. Tests use
synthetic upstream responses and do not consume live Lightcast quota.

See the [runtime example](https://lawwu.github.io/mcp-lightcast/architecture/#runtime-example)
and [migration guide](https://lawwu.github.io/mcp-lightcast/migration/).

## Install

```bash
uvx --python 3.14 mcp-lightcast@0.4.1 --env-file .env --transport stdio
```

```bash
docker run --rm -i --platform linux/amd64 --env-file .env \
  ghcr.io/lawwu/mcp-lightcast:0.4.1
```

The Docker release also updates the moving `0.4` and `latest` tags.
